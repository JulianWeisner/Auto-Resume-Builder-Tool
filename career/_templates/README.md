# Record templates

These files are blank, copyable forms. They are never read as career evidence. Copy a block into a real collection, replace every `{placeholder}` and delete fields that do not apply. Field meanings are in the [reference](../../schema/experience-schema.md#field-reference).

| Template | Use it for |
|---|---|
| [grouped-collection/records.md](grouped-collection/records.md) | A new grouped collection, and the blank role, experience, outcome and education blocks for any grouped file |
| [organization/](organization/) (roles.md, projects.md, experiences.md) | One employer with many stories that needs its own folder |

Conventions:

- `{curly braces}` mark a value to replace. A record left with braces is unfinished.
- `null` means unknown. `[]` means none extracted yet, not proof of none.
- Copy the anchor line above each block and give it the record's ID in lowercase.
- Links in these files are written for where the copy will live (career/<group>/ or career/<organization>/), so some do not resolve from here.
