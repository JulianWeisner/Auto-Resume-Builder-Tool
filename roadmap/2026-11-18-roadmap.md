# Roadmap snapshot — November 18, 2026

[Roadmap](../ROADMAP.md) · **Status: snapshot, not a commitment.** Each roadmap is a new, dated file. Earlier roadmaps are not rewritten, so the history shows how the plan changes. The previous roadmap is [ROADMAP.md](../ROADMAP.md) (November 9, 2026). This file describes the tool's development; agents do not treat it as operating instructions.

## What changed since November 9

- The roadmap is organized by **user product elements** instead of by phases. The phase numbers stay as references in the components.
- Eight top-level elements. Everything else is a component that defines functionality, quality, user interface or user experience.
- **Application submission** and **interview preparation** are elements that may or may not be built.
- **Foundation** (evidence rules, privacy, any AI tool, setup, updates) is not a user element. It is an inherent part of the product.
- **Offer stage** is out of scope in the near and short term.
- **Career informed search** is a product element. It is built in the upstream personal tool and not yet ported.

## Status key

✓ built · ◐ partial · ○ planned · ◇ idea · — not in that track's scope

The **Product** column is this repository. The **Upstream** column is the upstream personal tool, where shared features mature first ([UPSTREAM.md](../UPSTREAM.md)).
