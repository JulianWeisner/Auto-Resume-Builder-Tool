# CV snapshot

**Empty until you fill it.** When your CV is first imported, an exact text copy is saved here as `Curriculum-Vitae.<YYYY-MM-DD>.md`, dated the day of import (Markdown text, not the original PDF or Word file). Imported records name that date as their `source_revision`. Record `source_lines` point to its line numbers, so the snapshot is never edited, reformatted or replaced. Later CV changes go in the top-level [Curriculum-Vitae.md](../../Curriculum-Vitae.md), and a new snapshot is only added alongside, never over, this one.
