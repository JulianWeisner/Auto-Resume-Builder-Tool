# Stage 3 — Cover letters and application answers

Part of the [agent guide](../AGENTS.md). **Load when:** the user asks for a cover letter or application answers. **Also read:** [claim wording](writing/claim-wording.md) and [plain language](writing/plain-language.md).

Input: a request for a cover letter and/or specific application questions, the selected job and available career evidence. Produce only the requested materials; a resume request alone does not require a cover letter.

- Use the Stage 1 map, selected resume and subsequent clarifications consistently, but verify factual claims against records or explicit user testimony. Generated resume wording is not a new factual source.
- **Cover letters** follow the [cover letter style guide](../templates/cover-letter/style-guide.md) and start from its [template](../templates/cover-letter/cover-letter.html) (or the custom template named in the [Documents preferences](../career/preferences.md#documents)): the résumé header, an optional role and requisition subject, a specific opening rooted in the user's recorded motivation, two or three relevant examples, a left-aligned sign-off and the optional personal signature. Deliver a PDF and check it as the guide describes.
- Answer the actual question directly. Follow word/character limits and requested tone; report counts when limits are supplied. A cover letter should develop a few relevant connections rather than repeat the resume bullet by bullet.
- **Portal questions** (salary, work authorization, sponsorship, links, start date, demographic self-identification): use the [Application answers](../career/preferences.md#application-answers) table exactly. Leave salary blank unless the user has recorded or given a figure, and send unrecorded answers back to the user.
- Use confirmed career goals and preferences for motivation questions. Do not invent enthusiasm, personal connections, salary expectations, work authorization, availability, relocation willingness or avoidance criteria. Ask only when an unanswered item materially affects the answer.
- Separate employer-facing copy from short private notes on evidence, limits or unanswered items when needed. Do not regenerate the resume or its full report unless requested or a material inconsistency requires a targeted correction.
- Track new durable testimony for the handoff. Drafting or approval of copy does not authorize submission, employer contact or changes to the career record.
